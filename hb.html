Chapter VI

Fixed Point

Choose the statement that survives being made into a statement about itself.

The stable answer is not true because of external facts; it is true because of its own loop.
Look for the sentence whose content and reference point coincide.
Chapter VII

Double Negation

Classical logic says: not not P gives you P.

Constructive logic is more suspicious: knowing that P is not impossible is not the same as having P in hand.

Choose the statement that is strongest constructively.
Three answers only remove a negation-shaped obstacle. One answer actually gives you the object.
Chapter VIII

The Missing Witness

You are told:

It is impossible that there is no valid birthday code.

Which response gives the strongest constructive information?

A constructive proof does not merely say the box cannot be empty. It opens the box.
Chapter IX

The Classical Fork

A locked panel asks whether the hidden word is YES or NO.

You may open the panel only if you can prove that assuming each option fails leads to contradiction.

Which principle lets you choose a side without directly seeing the hidden word?

The fork says: either P or not-P. Constructively, that fork is not always free.
Final Chapter

Gödel’s Birthday Machine

You now inherit a formal system F. It contains all previous puzzle rules.

G: “This sentence cannot be derived from the rules of this puzzle.”

Choose what happens to G.

Good. If F derives G, then F derives that G is not derivable. The system eats itself.

So, assuming F is consistent, G is not derivable. And that is exactly what G says.

The puzzle has a true answer which its own rules cannot certify.

bonus epilogue

Mini‑Syllabus: Paradox, Crisis, Foundations

A tiny after‑credits map of the ideas hiding under the game: self-reference, Russell’s paradox, formalism, intuitionism, logicism, and Gödel’s limit theorem.

1. The Barber Trap

Russell-style self-reference: does the barber shave himself? Either answer flips into contradiction.

Core idea: impredicativity

2. Russell’s Set

Let R be the set of all sets that are not members of themselves. Is R a member of R?

Core idea: unrestricted comprehension fails

3. Three Camps

Logicists sought mathematics in logic; formalists in symbol games; intuitionists in constructive mental acts.

Core idea: rival foundations

4. Hilbert’s Dream

Hilbert wanted secure axioms and finitary proofs that mathematics would never contradict itself.

Core idea: consistency proof

5. Double Negation

Classically, not-not-P implies P. Constructively, removing the impossibility of P may still fail to produce a witness for P.

Core idea: witness vs refutation

6. Gödel’s Knife

Any sufficiently strong consistent formal system leaves some arithmetic truths unprovable inside it.

Core idea: incompleteness

7. After the Crisis

The crisis did not end mathematics. It diversified foundations: set theory, type theory, category theory, proof theory.

Core idea: pluralism
